# Pokémon Story Bot — downloads oficiais

Este repositório publica somente instaladores, verificações de integridade e notas das versões
do Pokémon Story Bot. O código-fonte e o histórico de desenvolvimento ficam em um repositório
privado separado.

Use sempre a [versão mais recente](../../releases/latest). O próprio bot também consulta essas
Releases quando você escolhe **Baixar e instalar nova versão**.

O Windows pode mostrar um aviso de publicador desconhecido porque o projeto ainda não usa um
certificado comercial de assinatura de código. Antes de instalar, o bot confere a assinatura
própria do manifesto e o SHA-256 do arquivo baixado.
